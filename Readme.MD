Thinkr
Dump your thoughts. AI does the rest.
A creative workspace that helps you organize chaotic thoughts and extract design inspiration from your imagination.
🔥 Features
🧠 BrainDump Mode

Dump all your thoughts without filtering
AI automatically organizes into categories: Tasks, Ideas, Concerns, Health, Learning, etc.
One-click copy of organized results
Save to localStorage

🎨 MoodBoard Mode

Free-form canvas to draw/sketch
Upload reference images
Draw with multiple colors and brush sizes
AI extracts dominant colors and suggests complete design system
Get font pairing recommendations
Export your mood board

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript
AI: Groq API (Llama 3.2 90B Vision + Llama 3.1 70B)
Backend: Vercel Serverless Functions
Deployment: Vercel
Storage: localStorage (no database needed)

💰 Cost
100% free forever — Groq provides free API access

🚀 How to Use
BrainDump

Click the 🧠 BrainDump tab
Type anything that's on your mind (tasks, ideas, worries, etc.)
Click "Organize with AI"
Get instant categorized results
Copy or clear to try again

MoodBoard

Click the 🎨 MoodBoard tab
Draw on the canvas OR upload reference images
Click "Generate Palette"
Get your color palette + design vibe + font suggestions
Copy colors to clipboard
